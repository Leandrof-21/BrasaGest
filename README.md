# BrasaGest
Sistema de gerenciamento de estoque integrado a um cardápio digital para a espetaria (Churrasquinho do Baiano). Permite ao cliente fazer pedidos pelo cardápio e ao funcionário controlar pedidos e estoque.

## Tecnologias

- Java (JDK 8)
- JavaFX
- Eclipse IDE
- Maven
- PostgreSQL
